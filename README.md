## 📌 Sobre o Projeto

Este repositório hospeda a minha página pessoal e currículo online, publicado via **GitHub Pages**. O objetivo foi aplicar na prática o controle de versão, organização de branches e publicação de páginas estáticas.

### ✨ Diferenciais Implementados
* **Layout Responsivo:** Adaptado para visualização tanto em computadores quanto em dispositivos móveis.
* **Hospedagem Automatizada:** Deploy contínuo diretamente pela branch principal (`main`) no GitHub Pages.
* **Download de CV:** Opção direta para visualização e download do currículo em PDF.
